# MERN Learning Journey

A structured record of my Full-Stack Web Development learning using the MERN stack.

## What I Am Learning

- **HTML** — Structure and semantics
- **CSS** — Styling, Grid, Responsiveness, Animations, Tailwind
- **JavaScript** — Fundamentals, Functions, Arrays, Objects, OOPs, Async JS
- **DOM** — Manipulation, Events, Event Delegation, Projects
- **React** — Components, Props, State, Hooks, Router, Redux, TanStack Query
- **TypeScript** — Essentials, Working with React
- **Node.js & Express.js** — Backend, CRUD, Protocols
- **MongoDB** — Database, Cluster, CRUD, Integration
- **Git & GitHub** — Version control and collaboration

## How Each Lesson Is Organized

Each lesson folder contains:

- **Learning/** — Code written while following the course
- **Practice/** — Code independently written after learning
- **README.md** — Topic summary, concepts learned, and notes
